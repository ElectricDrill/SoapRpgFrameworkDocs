# Context — Astra Framework Docs

This folder contains the working context for AI assistants operating on the Astra Framework documentation.

In this repository, `context/` is the canonical equivalent of the `.ai-context/` folder used in other Astra documentation repos.

## Files

| File | Read when... |
|---|---|
| [`style-guide.md`](style-guide.md) | Before writing or editing documentation text |
| [`source-reference.md`](source-reference.md) | Before inspecting package source code or documenting package behavior |

## How to use this folder

1. Read this folder before changing docs
2. Follow `style-guide.md` for all prose and markdown formatting decisions
3. Use `source-reference.md` to locate the framework package and the most relevant source folders
4. Edit `DocFx/` sources, not the generated `docs/` output
