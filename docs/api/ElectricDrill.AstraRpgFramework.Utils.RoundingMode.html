Ceil = 2

Rounds up to the smallest integer greater than or equal to the value (e.g. 2.1 → 3, −2.9 → −2).

Floor = 1

Rounds down to the largest integer less than or equal to the value (e.g. 2.9 → 2, −2.1 → −3).

Round = 0

Rounds to the nearest integer, with midpoint values rounding away from zero (e.g. 2.5 → 3, −2.5 → −3).
