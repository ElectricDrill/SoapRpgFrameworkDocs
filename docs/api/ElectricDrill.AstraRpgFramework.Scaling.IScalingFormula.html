Defines the contract for evaluating a scaling formula against one or two entities.

Implementations include:

  • ScalingFormulaSO – a shared ScriptableObject asset with no per-entity state.
  • ScalingFormulaInstance – a per-entity runtime wrapper that supports temporary scaling components without affecting other entities that reference the same ScalingFormulaSO.
