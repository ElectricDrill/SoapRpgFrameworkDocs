Namespace ElectricDrill.AstraRpgFramework.Config

Classes

AstraFrameworkConfigProvider

Static provider for the Astra Framework configuration. Uses a three-step fallback strategy:

  1. Project Settings (via AstraFrameworkGlobalSettingsSO).
  2. Conventional Resources location (Resources/Astra Framework Config).
  3. Logs an error if no configuration is found.
Call WarmUp() early (e.g., from a bootstrap) to pre-load the configuration. In tests, use the Instance setter to inject a mock configuration.
AstraFrameworkConfigSO

ScriptableObject that stores the global configuration for the Astra Framework. Holds references to the global game events and shared stat bindings used by core entity components.

AstraFrameworkGlobalSettingsSO

Internal ScriptableObject that lives in a Resources folder and holds a reference to the active AstraFrameworkConfigSO profile. Used by AstraFrameworkConfigProvider as the first-priority config source, and surfaced in Project Settings via the editor settings provider.

Interfaces

IAstraFrameworkConfig

Configuration contract for the Astra Framework base system. Provides access to the global game events that are dispatched by the core entity components (EntityCore, EntityLevel, EntityStats, EntityAttributes).
